# Vestibular IPEDE 2027.1 – Página de inscrição

Página pública de inscrição do Vestibular IPEDE 2027.1 (Faculdades IPEDE – Codó/MA).

- **Página:** `index.html` (publicada pelo GitHub Pages)
- **Fluxo:** inscrição → redação online → contato com a recepção pelo WhatsApp
- **Dados:** enviados ao Google Apps Script (`apps-script/Codigo.gs`), que grava na planilha "Inscrições – Vestibular IPEDE 2027.1" (abas Leads e Redações)
